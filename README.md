# EDS223-HW2: Legacy of redlining in environmental (in)justice
This repository houses materials for HW2 for UCSB's Masters of Enviornmental Data Science course EDS223.  

This project explores redlining in LA County and current disparities in income, air pollution, life expectancy, and traffic accidents according to historical HOLC rankings.

## Data access
Demographic ata was initally accessed from the U.S. Environmental Agency's EJScreen (Environmental Justice Screening and Mapping Tool).  The EPA does not currently support the tool, but an unofficial version can be found [here.](https://pedp-ejscreen.azurewebsites.net/)

HOLC redlinng data was accessed from the Digital Scholarship Lab at the University of Richmond's Mapping Inequality Project.  Their data can be found [here.](https://dsl.richmond.edu/panorama/redlining/data)

Crash report data was obtained from UC Berkely SafeTREC's Transportation Information Mapping System(TIMS).  Data from 2020 to 2025 is used in this analysis.  THe TIMS can be accessed [here.](https://tims.berkeley.edu/)
